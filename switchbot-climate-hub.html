How to Get Your Own App / APK

Zero Gemini wrappers — pure standalone experience

Method 1: Standalone Web App (Recommended) 10 Seconds

Progressive Web Apps run 100% full-screen without address bars or Gemini menus, exactly like an APK from the app store:

  1. Tap "1. Download App File (.HTML)" below.
  2. Upload it for free to tiiny.host or app.netlify.com/drop to get your personal link.
  3. Open that link in Chrome on Android (or Safari on iPhone), tap the 3-dots menu, and select "Install app" or "Add to Home screen".
Method 2: Generate an actual .APK File Android App

If you specifically want a downloadable .apk file to install on your Android phone:

  1. Download the index.html file using the button above and host it on Netlify or GitHub Pages (takes 30 seconds).
  2. Go to a free web-to-APK converter like WebintoApp.com or PWABuilder.com (both are free).
  3. Paste your website URL, and it will automatically generate and download your custom .apk file for you to install!
